# ColdPlay

A Minecraft 1.8.9 client. Requires 64-bit Java 8.

[Download JAR](https://github.com/Un-kn-0W-n/ColdPlay/releases/latest/download/ColdPlay-1.8.9.jar) · [Download ZIP with configs](https://github.com/Un-kn-0W-n/ColdPlay/releases/latest/download/ColdPlay-1.8.9.zip)

The JAR needs the [launcher JSON](https://github.com/Un-kn-0W-n/ColdPlay/releases/latest/download/ColdPlay-1.8.9.json). The ZIP includes both files and all six configs. See [installation instructions](INSTALL.txt).
